# 静话：基于 Pixel Telo 的个人防骚扰分支

用途：自用和开源。上游：https://github.com/Pixel-Tailor-CN/PixelTelo，保留 Apache-2.0 许可证。当前源码已公开在 [QuietCalls](https://github.com/Lucian-Wang/QuietCalls)。

独立包名 wang.lucian.quietcalls（debug 为 wang.lucian.quietcalls.debug），可与上游共存。首次启动默认离线识别、实际拦截模式；所有新增拦截规则默认关闭，集团短号默认允许，用户在设置“规则拦截”中启用所需策略。

优先级：确认通讯录联系人 → 单号码白名单 / 内部短号 → 明确黑名单 → 境外/港澳台规则 → 骚扰识别与推销规则 → 地域豁免后的陌生号码规则。

集团短号严格为 6 开头、共 3–5 位数字。地域白名单仅豁免陌生人拦截，不会提前放过本地骚扰库和在线识别命中。支持独立精确号码通行列表，也保留上游名单管理。

地域由内置 phone.dat 离线查询手机号码和带区号固话；数据更新至 2025-02，许可及固定版本见 third_party/。归属地不是实时位置；无法确定地域不会自动命中地域白名单。

未授权、查询超时或联系人 Provider 失败时保守放行，避免将联系人误判成陌生人。在线识别失败不会覆盖已完成的本地规则决定；识别查询总预算约 4 秒，保留系统来电响应余量。来源失败仍单独显示，不作为正常号码。

配置入口：设置 → 来电识别 → 规则拦截。规则受“仅提示不拦截”和重复来电策略影响，用户可在同页调整。

构建需要 Java 21、Android SDK `platforms;android-37.0`；命令见 [README](README.md#构建)。当前 CI 执行 `:app:assembleDebug` 和 APK 包名校验，本地可另运行 `:app:lintDebug`。真机验收需验证默认来电筛选角色、联系人权限、双卡和号码格式。

0.2：统一静话名称与盾牌电话图标；中间导航为设置，原自定义移至黑白名单。号码通行名单逐条增删改，地域通过可搜索多选列表管理。移除上游推广、反馈、号码上报入口，停用旧标签白名单。新增虚商（162/165/167/170/171，11 位）、400（10 位）、95/96（5–20 位）独立开关，默认关闭。国内 +86/0086 格式同样匹配，其他国际号码不当作国内号段。指定号码与联系人优先，地域通行不豁免号段规则。

0.3：设置改为分类面板：常规拦截、特殊号段、陌生号码通行、拦截行为、离线库、在线识别、权限、显示提醒、备份与关于。每项规则只有一个编辑位置。来电记录顶部统一显示接管/权限/号码库就绪状态，按钮直接到当前缺少的步骤。黑白名单显示条数并说明作用；号码输入自动聚焦并使用电话键盘，通行条目删除需确认。本地标签不再显示、查询、编辑或参与备份恢复；旧表保留兼容历史数据库。

0.4：保留黑白名单主入口和黑/白两类，仅保留号码与地域，取消自定义标签选项及匹配。号码表单简化，地域采用共享搜索多选目录，逐条显示和删除，黑名单地域离线拦截，白名单地域豁免陌生人。联系人及指定号码白名单优先。

0.5：白名单只管理号码/前缀，直接放行；地域通行独立且仍受骚扰与特殊号段等规则影响。旧白名单地域自动迁入设置的地域通行列表，先持久化后移除，去重且可重试。首页提示卡默认收起详情，设置概览缩小，规则说明按需展开。

0.6：实际拒接后发送单条静默聚合通知，低重要性、无声音/振动，展开显示最近5条和总次数。点击打开来电记录；进入应用或划掉后清零。通知授权及渠道入口在来电显示与提醒中。通知未读摘要不参与系统备份，锁屏公开版本隐藏号码和原因。

0.7：设置新增运营商协同防护，提供三家官方名称、办理渠道、资料链接及拨号咨询。网络侧与静话本机防护独立，不自动订购、不假定开通，不新增SIM/电话/SMS权限。

0.8：默认在线识别改为 HTTPS 直连 360，不经过原实时查询中转，号码直接发送至 360；保留“不联网查询”开关和自建服务隔离。旧搜狗配置不继承，默认 source 固定为 360。空数据和有效无标签卡片显示“暂无标记”，不意味着号码安全；未知标签仅展示，明确骚扰类别才参与拦截。查询失败或超时放行，取消同步终止网络请求，不新增权限。离线库同步继续独立运行。
